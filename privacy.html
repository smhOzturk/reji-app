Privacy Policy

Last updated: October 23, 2026

Reji is a personal, single-user tool. Only its owner uses it, with the owner's own Google account.

What data is accessed

With the owner's permission, Reji reads the owner's YouTube channel information and YouTube Analytics reports (views, watch time, audience retention and similar statistics) using the read-only scopes youtube.readonly and yt-analytics.readonly. It does not request write access.

How it is used and stored

The data is used only to display statistics to the owner. It is stored only on the owner's own computer. It is not sold, shared with third parties, or used for advertising.

Revoking access

Access can be removed at any time from inside Reji ("Disconnect") or from Google Account permissions. Disconnecting deletes the stored token.

Reji's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
